# 🚀 TestRail Document Generator (TestRailCloneServ)

Простой и удобный инструмент для автоматической генерации официальных документов (в формате `.doc`) на основе тест-кейсов. Проект создан с заботой и предназначен для быстрого формирования отчетов без лишней рутины.

---

## 🛠 Технологии

Проект состоит из двух частей (клиент-серверная архитектура):
* **Back-end:** Java 17, Spring Boot (отвечает за логику генерации документов).
* **Front-end:** HTML, CSS, JavaScript (удобный пользовательский интерфейс).

---

## 📦 Быстрый запуск для пользователя

Для запуска приложения не нужно настраивать сложные среды разработки. Достаточно выполнить всего один шаг:

1. Убедитесь, что на компьютере установлены **Java 17+** и **Python** (для локального веб-сервера).
2. Запустите соответствующий скрипт в зависимости от вашей операционной системы:
   * **Windows:** Дважды щелкните файл **`start_win.bat`**
   * **macOS:** Дважды щелкните файл **`start_mac.sh`** (предварительно дав права на выполнение `chmod +x start_mac.sh`)
3. В открывшемся окне браузера автоматически откроется страница генератора!

> 🛑 **Как остановить работу:**
> * Просто закройте черные окна терминала (серверов), которые открылись при запуске.
